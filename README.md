# slots-frontend
ttk-slots-fronend

Меню описано в файле [AppSidebar](/src/layout/AppSidebar.js), в пункте меню в переменной to указан относительный путь, который будет установлен в адресной строке

Привязка компонентов к относительному пути выполняется в файле [Routing](/src/Routing.js)

Пример страницы для выполнения какого-то действия (генерации слотов, отправки почты и т.д.) [CreateSlotsPage](/src/views/create-slots/CreateSlotsPage.js). В компоненты расположена форма с параметрами, при отправке форме используется хук для отправки запроса на сервер: [useGenerateSlots](/src/hooks/slot/useGenerateSlots.js). В запрос передаются параметры и функции для обработки успешного и ошибочного ответа.
